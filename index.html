Panduan Upload Website Ini ke GitHub Pages (100% Gratis)

Ikuti langkah mudah ini untuk menjadikan website toko/komunitas milikmu online gratis selamanya.

1

Buat Repositori Baru di GitHub

Buka GitHub.com, buat akun (jika belum ada), lalu klik tombol hijau "New" atau "+" di pojok kanan atas untuk membuat repositori baru.

Beri nama repositori misalnya: madan-store dan pastikan diset ke Public.

2

Buat File `index.html`

Di dalam repositori baru kamu, klik link "creating a new file".

Beri nama file wajib: index.html (jangan ganti nama lain agar otomatis dibaca GitHub Pages).

3

Copy & Paste Kode Lengkap

Salin semua kode HTML/JS dari file ini, lalu pastekan ke dalam editor file `index.html` di GitHub. Setelah itu scroll ke bawah dan klik "Commit changes...".

4

Aktifkan Fitur GitHub Pages

Buka tab Settings di menu atas repositori kamu -> pilih menu Pages di sidebar kiri.

Pada bagian Build and deployment -> Branch: Ubah dari None menjadi main (atau master) -> Klik Save.

Selesai! Website Kamu Sudah Live Tunggu 1-2 menit, domain website kamu akan siap diakses di URL: https://username-github-kamu.github.io/madan-store/
